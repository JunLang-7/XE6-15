为什么不是普通日历05

纸条、闹钟和家人提醒，都只解决了一部分问题

现有方式它能解决什么仍然缺少什么
纸条 / 便签能写下安排刚想到时不一定在身边，容易漏写或忘记查看
普通闹钟能在固定时间响起不知道提醒的具体内容，也不能处理“稍后提醒”
家人转告当下有人帮忙记住儿童尚未形成稳定的记录与处理习惯
手机日历功能完整需要个人终端和多步操作，不适合儿童随时使用

他们需要的是：当下说出来，之后被提醒，变化时还能自己处理。

工程质量14

从单元测试到实板证据，质量是一条可复核的链路

单元测试

当前工作树 C++ 主机测试 95 项，91 项标记为 unit，95/95 通过；当前工作树 IM Gateway 回归 343 项，340 通过、3 跳过；Python 工具测试 198 项，197 通过、1 跳过。

覆盖率 / CI 门禁

远程 main 的 Codecov 勋章显示：总体 90%，C++ 90%，TypeScript 92%。CI 同时执行格式、类型、ESP32-S3 构建与 CodeQL。

集成 / 契约

4 项 integration + 20 项 contract，覆盖 Schedule、Timing、Storage、IM 的组件拼装与 Port 输入输出契约；并覆盖串口、Linx MCP、IM 契约边界。

端到端测试

Host/HIL E2E 固化日程CRUD、提醒触发响应、IM推送响应三条 journey；从设备事件到 Gateway、动作回执和“已消费”全链路状态，产出脱敏证据。

质量门禁：每项能力都要有测试结果、覆盖率与可复核证据；实板行为以 HIL 记录收口。
